# 人生手账：手机反馈核查与本地补修

日期：2026-10-24。基于用户三张小米浏览器实机截图及本地源码核查。状态：**本地已实现，未提交、推送或更新云端**；当前线上仍是 `21b7dbae`。本轮未读取真实个人记录或调用真实供应商。

## 用户问题与处理

| 反馈 | 核查结论与本轮处理 |
| --- | --- |
| 计划、照顾自己内容默认展开，页面过长 | 每项默认显示名称、排期、补充说明和已保存状态，填写/更正/历史由用户展开。保存当次结果后收起。列表先展示四项，可主动查看全部，未删除其他项目。 |
| 照顾自己不适合要求预计分钟 | 编辑时改为可选“补充信息”，作为项目小字展示，存于既有 rule JSON 和版本快照。旧预计时长保留，不清空历史；行动计划仍可设预计分钟。 |
| 事件记录没有体现属性点 | 模型原有 changes 会返回，但原展示不醒目。现在分析区先展示属性建议，确认后只读关联真实结算判定的 final_changes，显示实际入账点数，避免把 +1 建议冒充置信度加权后 +0.9 的实际变化。金币同区汇总，仍需预览和确认。 |
| 第一次分析失败，后来成功 | 用户确认找不到当时报错；本地没有该云端任务证据，**根因未确定**。新增折叠任务历史，展示最近20条事实分析的时间、状态、安全错误编号和受控说明。未声称已修复真实供应商故障；未增加无限自动重试。 |
| 分析确认后仍留在首页待办 | 已定位：旧 pending 只检查 AIJudgment，漏掉新版 FactBundle 的确认状态，零奖励组尤其不会生成已确认判定。现在检查当前原文/许可版本的事实组，并保留后续主动分析的待处理状态。首页提交分析后和回到可见状态时重新读取摘要。 |
| 排序数字难懂 | 项目表单和列表不再暴露位置整数；提供“调整顺序”下的上移/下移。后端一次提交整组键与版本，在用户锁和回执事务内完成排序；不改排期历史和当次结果。 |
| 奖励只有停用，越来越多 | 新增“移除奖励”及确认。当前列表只显示启用奖励；已移除/停用奖励默认收起，可恢复。移除停止自动价格检查，保留商品身份、旧券、账目和余额，不物理删除关联历史。 |
| 首页和页面间跳转冗余 | 首页钱包、待处理和日记合并为快捷入口；今日片段默认收起，最多预览三条，完整内容到手账；“项目与目标”指向统一计划管理。已有返回来源机制保留。 |
| 手机编辑弹窗要滑很长 | 缩短默认字段；次要日期与目标收起，指定日期/间隔日仍展示所需日期。保存/取消操作栏固定，使用动态视口高度，焦点范围包含实际可见控件与 summary。 |
| 内容日期仍是混合占位 | 保留10月22日已完成但未发布的补修：手账内容日期为空显示“全部日期”，完整文本日期校验与清除筛选，未改筛选口径。 |

## 各页面组织检查

| 页面 | 默认展示与按需展开 |
| --- | --- |
| 今天 | 保留记录输入、待处理数、首记领取及当日安排；压缩重复入口，今日片段按需打开。读写错误不藏入折叠区。 |
| 计划 | 项目为主，目标与进度、主线、阶段背景和旧次数项目收起；新建目标表单默认收起。 |
| 事件详情 | 原文仍可阅读；内容与标题相同或标题是原文开头时，不再重复整段大标题。确认后的分析、依据、任务历史、许可及撤销操作收起。待核对建议与分析等待状态保留可见。 |
| 晚间日记 | 原文和主动操作保留；已回答/跳过的回顾问题收起，未回答问题保留展开；原文、AI问题、本人回答继续分开保存。 |
| 成长 | 核心数值保留，趋势按需展开；沿既有 ResizeObserver/切换逻辑恢复图表渲染。没有隐藏或重算属性。 |
| 奖励 | 添加心愿表单默认收起，成功后关闭；价格和兑换保留可见，定价依据/管理、归档、娱乐约定及流水按需展开。仍由本人模型定价。 |
| 计时 | 当前计时、暂停/继续、结束确认保留；意外说明和手工用量调整收起，历史保持折叠。 |
| 我的/设置/账号安全 | 去掉默认暴露的原始时区标识；模型、导出、备份与改密/邮箱/会话管理按需展开，设置目录会展开目标的祖先面板。内部日期规则与原时区数据保留。 |
| 长期信息 | 已保存条目显示摘要，展开编辑；新增条目立即打开，保存后收起，授权用途不改变。 |
| 反馈与公告 | 历史反馈内容/回复、公告正文按标题展开；私密反馈权限不变。 |
| 待处理 | 依状态分组，每组先显示六条，可查看全部；已确认的新事实不再占位。 |
| 其他入口 | 问卷/回归保留逐题向导；重要日子保留列表与编辑弹窗；报告仍选择后打开；旧挑战和特殊券保留现有分段导航，不因缩短页面删除旧合同。 |

“默认收起”保留原文、草稿、审计与历史，不等于删数据。实际待确认、错误及等待状态保持可见；页面合理滚动仍存在，没有承诺任意数量数据都能一屏展示。
