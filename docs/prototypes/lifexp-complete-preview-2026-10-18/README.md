## 建议体验

1. 今天“填入体验文字”→选择保存后现在分析→检查建议→确认入账；到成长看 13 维变化和入账依据。
2. 手账搜索原文、切换分类、翻页；事件详情可编辑、查看旧版本，或明确关联同一事实，不会自动合并。
3. 保存一篇日记→帮我回顾→回答／跳过→结束；编辑原文后查看旧问答的依据仍保持原样。
4. 自建目标和排期；切换预览日期确认周一的计划不会堆到周二；计划结果可关联已入账事件。
5. 奖励商店“添加想要的奖励”→看 AI 定价建议→接受→兑换。两张娱乐券分别计时；第一张剩 25 分钟时，新券仍有完整 30 分钟。
6. 我的→模型：填错模型名，保存后测试，看失败提示；本机模拟用 `demo-chat-model` 或 `example-chat` 可通过，不代表真实模型 ID。API Key 输入禁用，不收集真实凭据。
7. 我的→导出：四种格式均可生成并下载。辅助问题／回答／分析分开标注。
8. 我的→登录注册体验，注册无需邀请码；完成模拟验证后可登录新账号，看独立建档。原示例账号为 `xiaolin`，示例密码字段已填好，不需要真实密码。
9. 提交反馈→右上角完整目录进入管理体验→回复；发布公告、搜索和停用恢复用户、修改注册开关；返回普通体验验证联动。

右上角的日常／冲刺／节日／回归／首次建档场景和“重置”会载入新的**虚构状态**，请先下载想保留的体验意见。新命名空间是 `lifexp-complete-preview-20261018-v1`，旧 Demo 与正式数据库不受影响。

## 方案边界

- 这是功能范围完整的**本机交互预览**，供确认整个系统的流程和布局；模型、邮件、认证与管理权限均为脚本模拟，金额与输入只保存在当前浏览器。它不是正式应用实现或上线验收。
- 金币试用规则和实际保存日口径沿用已确认方案；基础娱乐采用“首记解锁独立免费时长”展示，仍待最终确认。挑战示例保留旧合同 5 币押金／12 币奖励，不将其当成新的正式价格政策。
- AI 奖励初次定价的模拟只演示参考金额／时长与阶段变化；不冒充真实个性化模型分析。事件匹配、回顾主题避重、周期报告、发现型成就也是有限主题脚本，正式版本需要真实模型与服务器验证。
- 必要休息不收费；特殊安排页面保留说明／核对入口，本轮没有将复杂预约券和分期政策重新定稿。
- 通用 AI 聊天、站点共享付费模型、复杂预约分期、App／小程序、真实旧库迁移和公网部署仍按之前决定暂缓，不是此 Demo 中被偷偷删掉的已确认功能。
- 确认此 Demo 后才定稿交 Writer 完整开发。本目录没有启动 Writer、修改正式应用、发送邮件、发公告到云端或访问真实数据库。

## 源码与验证

`core.js` / `core.css` 保留最近增量交互；`system.js`、`journal.js`、`account.js`、`admin.js`、`boot.js` 补齐统一模块与联动；`full.css` 是多端补充布局。所有源文件都在本目录，无需跳转或运行旧 Demo。

```powershell
python -B docs/prototypes/lifexp-complete-preview-2026-10-18/build.py
node docs/prototypes/lifexp-complete-preview-2026-10-18/check-preview.mjs
```

build.py 对合并后的完整脚本做语法检查，再生成单文件 HTML。浏览器检查使用隔离的隐藏 Edge 和本机临时回环服务，最终关闭自有浏览器和服务。四种实际下载文件在临时测试目录核验。

验收由两部分组成：**逐模块目录覆盖**（每个页面桌面／手机访问及布局）＋**关键行为验证**（确认前不写账、属性累计、同事实防重、多轮问答、两张券、模型错误、账号工作区、四种下载、管理联动等）。最新真实结果见 qa-summary.json；失败记录 FAIL，不用旧通过数冒充新结果。
