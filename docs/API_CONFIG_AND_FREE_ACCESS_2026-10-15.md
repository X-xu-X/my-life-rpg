## 1. 核对后的费用结论

| 供应商 | 官方页面能确认的事 | LifeXP 应如何说明 |
| --- | --- | --- |
| SiliconFlow／硅基流动 | 价格页确有免费模型，例如对话区 `XingChenAGI/Xing4.0-29B` 标免费；也有翻译/向量/OCR 等免费项，能力不同 | 有免费模型选择，但不是所有模型免费；限流/账号权限/能力适配需按当前模型页核实 |
| DeepSeek | 价格页按输入/输出 token 收费，余额包含充值或赠送部分，赠送部分优先抵扣 | API 是按量计费；不能保证每人有赠送额度，更不能称永久免费 |
| OpenAI | 官方文本模型价格表按用量计价 | 不能把它作为默认永久免费文本 API；账户优惠/试用以实际资格为准，不承诺每个新账号都有 |

依据：[硅基流动价格](https://www.siliconflow.cn/pricing)、[DeepSeek 价格及扣费规则](https://api-docs.deepseek.com/quick_start/pricing/)、[OpenAI 官方 API 价格](https://developers.openai.com/api/docs/pricing)。本记录仅归纳本应用所需的文本分析路线，不以其他免费工具或审核接口替代文本模型分析。

**两个区别必须讲清**：网页聊天免费不等于第三方应用可免费调用 API；限时/一次性赠送额度不等于某模型长期标价零费用。实际使用及模型是否提供 JSON/兼容接口、输出质量、速度和限流尚须独立验证。不能给免费但不适合日记分析的翻译/OCR/向量模型贴“推荐分析模型”。

原始价格页可能更新，示例模型只作查询时证据，不固定为永久默认模型。开发前重新核验，不因免费项下架自动切成收费模型。

## 2. 不愿付模型费用的用户也能使用

现有无模型路径可记录原文、回看、手写日回顾及导出，不要求绑定 Key；首次游戏建档可选未评估基线。AI 分析、AI 问卷或 AI 报告才需要对应可用模型。

产品说明应先呈现“不绑定 AI 也可以记录”，不要让用户以为必须买 Key 才能登录、注册或写日记。应用托管成本与用户模型 API 费用是两件事，本记录没有决定未来产品收费政策。

如需额外实现“严格只用免费模型/禁止收费回退”的模式，应单独确认模型价格来源、更新/失效机制及回退约束；当前并不存在可靠实时价格检测，不写成已支持的功能。至少不能在帮助里承诺“免费”，实际却不说明主辅配置可能回退到收费模型。

## 3. 已明确需要的配置帮助

用户本次问“是有配置步骤和官方跳转链接的吧”，本轮正式方案应明确包括以下内容，不仅写“优化配置体验”。

1. 在模型卡片就近提供“第一次配置？跟着步骤来”。
2. 选供应商，打开对应官方控制台；说明这是供应商账号，与 LifeXP 登录不同。
3. 在官方控制台创建 API Key，不让用户把 Key 发给 agent/聊天/Issue。
4. 打开官方模型与价格页面，核对费用、能力及账号权限，复制准确模型 ID。
5. 返回 LifeXP，填 Key 和模型 ID，先配置主组即可，辅助组可稍后。
6. 保存显示“已保存，尚未验证”，显示准确 provider/model/用途；未保存编辑与当前值区分。
7. 用户主动点测试，显示“测试中→通过/失败原因”；明确测试范围、配置变更后结果失效。付费模型的测试本身可能产生调用费用。
8. 常见错误提供下一步：认证失败/余额或权限/找不到模型/超时/限流/不支持结构化输出，不统一写“原文已保存”。

步骤不强迫默认充值。免费模型的账号限制和真实测试结果应明示；模型不存在时保留输入，不自动替换成付费模型或读取平台公共 Key。

## 6. 新增讨论：站点默认 AI ＋用户自配模型（候选，未启用）

用户最新询问：免费模型应有容易找到的入口；若用户想 AI 分析、想免费又不愿配置，是否可以由站点运营者提前安排。**目前只是咨询与方案输入，用户尚未选择运营预算/共享服务范围；没有读取或启用 owner 的 Key。**

顾问建议对“自用＋身边朋友”采用双路径：普通用户可主动选站点提供的默认 AI，免配置；高级入口保留自己配置供应商和模型。不强迫全体用户注册供应商账号，也不把某个用户的私有配置默认为全站共享凭据。若暂时不做托管，第一阶段仍提供免费模型配置步骤和官方入口，但不能写成免配置已可用。

2026-10-15 再核对 [官方价格页](https://www.siliconflow.cn/pricing)：对话区 `XingChenAGI/Xing4.0-29B` 输入/输出标免费，可作为适配候选，尚未实测 LifeXP 判定和回顾质量。[官方限流说明](https://docs.siliconflow.cn/docs/userguide/faqs/rate-limit-and-upgradation)明确免费模型限流固定、需身份验证，限流按供应商账户而非每个 API Key；因此同一账号新建多个 Key 不能增加共享额度。遇 429 应排队/退避，不不停重试。无法据此承诺永久免费、无限调用或稳定性 SLA。

产品中区分“对用户免费”与“上游模型本身免费”。若免费候选不满足结构化判定、中文质量或吞吐，另一个选择是由运营者补贴小额付费模型并设置总预算；**这只是候选，需要用户确认预算，不默认充值、购买或切付费模型**。已有 1.6GiB 云主机不把自托管大模型推理作为无需额外成本的替代方案。

若用户确认托管路线，正式规格需覆盖：

- 服务端独立站点凭据，不下发浏览器、不复制到每个用户设置、不从 owner 私有 Key 自动回退；供应商侧接入规则核实后选用。官方协议有 Key 转让和转售限制，普通应用集成与分发裸 Key 不能混为一谈，见 [平台协议](https://docs.siliconflow.cn/docs/legals/terms-of-service)。本次未联系供应商。
- UI 明确“站点默认／我自己的模型／关闭 AI”，展示实际 provider/model、状态及额度说明。首次选用说明相关日记/事件将送往哪个模型服务商，用户主动开启，不把“默认选项”当成已授权后台分析所有内容。
- 每用户每日额度、站点全局调用/并发/token/重试与费用预算，异步任务预占和失败释放需有口径。数字待用户决定；额度用尽保留原文并提示稍后再试/自配，不静默调用用户的付费配置。
- 免费模式锁定经确认的模型白名单与价格状态，停用/限流/价格变化时暂停并反馈；不暗中回退收费模型。站点补贴方案只在运营者明确预算内调用，用户自配仍遵守其本人授权和预算。
- 模型身份、站点配置版本/停用版本、实际凭据作用域随任务保存；凭据是站点级也不能把事件、对话记忆、缓存、结果或账本跨用户共享。旧任务不能误用后来修改的模型完成判定。
- 免费候选先用虚构样例验证结构化输出、事件相关追问、回顾避免重复、错误/超时/429和取消；再在用户明确授权下测试真实供应商。页面定价证据不等于接口质量或共享服务能力已验收。

当前代码仍以 `LLMCredential.user_id` 隔离个人配置，配置摘要的 env_fallback 为不可用；站点默认模型是增量开发，不能只把一个公共 Key 写进前端或绕过原有隔离检查。候选方案已记录为 F32，尚不扩写成已批准生产切换。
