## 2. 先做 P1，可独立交付

1. 核对当前源码与工作区已有改动，列出 F01～F33 中本批涉及项。不要覆盖其他 agent/用户的未提交文档或真实数据。
2. 普通导航组织为今天/手账/计划/成长/我的，保留旧链接兼容。二级页提供返回，管理账号安全无来源回管理概览；返回不退出/切身份，账号切换清来源。
3. 模型摘要显示准确已保存配置、用途与版本化验证状态；测试已保存组，未保存输入先提示；通过/失败就近显示，测试中换配置旧结果失效。保存不隐式发请求；真实错误分类脱敏。
4. 新手帮助给配置步骤及官方控制台/模型价格/文档入口；重新核验官方链接和免费声明，说明测试范围/可能计费，不承诺永久免费或三家全免费。
5. 默认当天记事件，发生时间精度与保存时间分开，修改日期折叠；普通事件不追问整天作息。详情任务状态只读同步，离页/终态停止。
6. 去矛盾/重复文案，未评估基线不显示熟练；桌面/手机排版更短，长金额/模型名/图表标签可读。
7. 兑换使用页面内可访问对话框；原操作回执/未知结果恢复/原子扣币保持，券兑现不再扣币。不要把 UI 修改写成第二套兑换服务。

P1 不等主线金额、默认 AI 或邮箱预算，也不顺带启用它们。疑似同事实的新结算行为仍受 D03 约束。

## 3. 后续按依赖逐批推进

- **P2 记录/日记/回顾**：新类型与日期兼容；原文、AI 问题、用户回答和分析独立保存。先存问题再展示，未回答/跳过可恢复；来源快照与旧版本保留。辅助回答不拼正文、不增加日记日数/第三类奖励。
- **P3 计划**：主动创建日程，当天只见到期安排，总表保留。完成/部分完成先事实再建议再确认入账；未完成原卡片确认锁定，无补充页/成功 toast、无自动扣点。实际量不默认百分比。计划与旧事件关联不能重复发奖。
- **P4 导出/统计**：Markdown/离线 HTML 可读，JSON 保留本人游戏数据能力，CSV 明示扁平范围；带辅助内容必须保留确切问题。日期/旧分类/动态成就及导出默认组合按 D01/D02/D08/D10，未定部分明确关闭/待定。
- **P5 账号/管理**：直接注册不依赖邀请、主动改密；邮箱/旧恢复码过渡按 D04。独立管理端五类候选按 D11；服务端能力守卫，不能读他人日记或 Key。不要复制原型本地 role 开关。
- **P6 条件功能**：主线分档 D05、站点默认 AI D06、动态成就授奖 D08 只有具体规则确认后启用。未确认金币不编数、未确认预算不共用 owner Key，不静默回退付费。
- **E 工程独立修复**：将新空 PG 初始化秘密换行问题修回 `deploy/init-app-role.sql` 并隔离测试，不对当前库执行 ALTER ROLE，不删卷或重初始化。

遇未决项，只暂停对应受影响路径；继续不依赖它的工作。交付时区分可用、关闭候选和未实现，不把全部模块画了界面就标完成。

## 4. 实施合约与迁移

每批开始列出最小数据模型/API 变化和兼容策略，最终回写总计划或交付记录：

- 不改已执行 Alembic，cloud 显式新 revision。旧 source/原文/历史账本、已评估画像不猜测回填或清理。
- 新表/外键/多态关联有本人归属；管理能力服务端判定；GET 不发奖、不调用模型。
- 所有结算复用既有服务与 profile 锁顺序；同事实/当次唯一约束、UUID/指纹/版本/回执并用，金币/属性/审计/回执同事务。
- 模型调用在事务外，核对内容/配置/租约/停用快照后写回；失败/取消/过期不覆盖新内容，不丢原文。
- 新导出实体白名单与 schema 版本、导入映射/拒绝策略同步更新，不能导出凭据/令牌。
- 生产使用原认证，旧 owner/user 角色明确映射，不建立绕过 Session 的第二套管理登录。

## 5. 验证和交付格式

使用总计划 A01～A17 场景逐项报告。每批只运行有意义的规则/集成回归、前端构建及浏览器关键流程；事务/竞争需独立 PG，模型/邮件先替身，真实接入另记授权/测试边界。

Demo 的 97 项通过与 36 张截图只证明虚构交互脚本，不照抄为应用验收结果。没有环境写 NOT_RUN，跳过不算通过。修改后 `git diff --check`，按逻辑单元中文提交；具体 commit/push/分支操作以接到的执行授权和当时仓库规则为准，不默认自动 push。

每批交付至少包含：

1. 已修反馈编号、实际变更文件与最终行为。
2. 新迁移/API/配置开关和旧数据兼容。
3. 命令及真实 PASS/FAIL/SKIP/NOT_RUN，桌面/手机关键截图。
4. 剩余 D 项、失败/风险/回退步骤，下一批依赖。
5. 实现状态回写与必要使用说明；不把代码完成写成已部署。

本任务书不包含：真实数据迁移/删除、云端重建、公网开放、证书/DNS操作、真实邮件/公告发送、默认模型充值/启用、GitHub Issue/PR发布、App/小程序工程。需要这些动作时再按具体任务办理，不能因先前某次发布授权而默认本轮也获授权。
