## 私有访问通道断开：补充记录

2026-10-12 用户截图显示 `client_loop: send disconnect: Connection reset`。这是 SSH 连接被重置的证据，不直接证明网页程序退出，也不能仅凭截图确定是空闲超时。可能涉及网络切换、电脑休眠、中间设备空闲连接回收或服务器端断开；未读取服务器日志，不下唯一根因结论。偶发断开可重连，频繁发生需要进一步定位。

原命令没有启用 SSH 协议保活。可在用户电脑 PowerShell 中、旧连接已经结束后使用：

```powershell
ssh -i "$env:USERPROFILE\.ssh\lifexp_ed25519" -N -T -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -o ServerAliveCountMax=3 -L 127.0.0.1:443:127.0.0.1:8443 admin@116.62.38.231
```

参数已通过本机 `ssh -G` 检查：无服务器数据时每 30 秒发送保活，连续 3 次无响应则断开；不保证电脑休眠或实际网络断开时仍保持连接，也不自动重连。依据：[OpenSSH 配置手册](https://man.openbsd.org/ssh_config#ServerAliveInterval)。输入私钥口令后保持窗口开启，重连后刷新专用浏览器；无需因此重建或重启应用。

该通道仅用于备案等待期的私有访问。完成公网切换后，普通网站访问不再依赖用户电脑上的 SSH；服务器管理仍可能需要 SSH。此记录未修改用户 SSH 配置、读取私钥或实际发起新连接。
