## 建议体验顺序

1. **今天 → 填入体验文字 → 保存记录**。保存就解锁基础娱乐，不要求先调用 AI、正面情绪或属性入账。首记 3 币另行领取，每天一次。
2. **手账 → 这条事件 → 分析这件事（模拟）**。直接展示属性、金币与目标关联建议，不要求自己选成果档位。关联不对可补充／修正。事实不足时先围绕本事件补充，不凭空发奖。正式版本由 AI 据事实建议并经规则核验；本版只用简化脚本演示。
3. **今天或成长→奖励与娱乐 → 开始基础娱乐**。开始/暂停/继续/结束；展开“Demo 时间控制”快进、接近结束、超时或模拟中断，不必真的等待半小时。刷新可以恢复。
4. **计时 → 说明情况**。填写原因和实际分钟数，查看单次模拟 AI 建议；明确保存后才改计时，结束时再核对金额。不会因网页关闭直接罚币。
5. **今日计划 → 开始计划/完成/部分完成/未完成**。计划计时结束仍需记录实际完成情况；可关联已经保存的事件，同一事实不会重复领奖。未完成在原卡片内确认锁定。
6. **我的 → 详细问卷**。6 组、36 道题，每次显示一道；可逐题/整组跳过、离开恢复、提前查看建议。已建档只补背景，不再次发启动金币。右上角“首次建档”可体验从零到中性/问卷预览确认。
7. **我的 → 娱乐额度与奖励约定**。近期阶段、基础时长、温和/严格约定。可先看临考加强建议再确认；不会修改已经开始的计时规则或已经解锁的基础额度。
8. **奖励区 → 调整价格**。示例读取当前阶段和实际兑现次数，展示建议；紧张阶段可上调，放松后可降回基础价。已购买的券锁价，购买和实际使用分别记录。
9. **成长 → 记录天数与成就**。实际保存日统计累计、当前/最长连续。补记归到内容日，但不补过去的坚持天数。可载入 29 天虚构历史，再写今天日记体验 30 天里程碑；固定/动态等价奖励共用领取身份。
10. **晚间日记**。原文、确切 AI 问题、对应回答、示例分析分区保留；回答不写入日记原文，也不另增记录天数。
11. **切换节日/久别回归场景**。节日礼金和努力加成分别显示；回归短问卷可跳过，保存近况不重置初始面板或补发过去奖励。
12. **我的→意见与问题**提交一条反馈；右上角**审阅与意见→切换管理反馈体验**，管理员站内回复，再返回普通体验查看。界面说明默认双方可见；模拟角色切换不代表已实现服务器权限。

右上角“审阅与意见”可以保存对基础娱乐、排版、确认流程的选择和文字，并下载本机文本文件。它不会发送给 Writer；正式决定仍请在聊天中确认。

## 本轮反馈修订

- **计划与目标**：可创建／编辑自己的目标、说明及可选期限，并由自己设定主线。计划关联目标可不选；新增／编辑计划支持每天、工作日、周末、指定星期多选、每隔 N 天和起始日、单次日期、自行安排。
- **事件分析**：移除手动成果档位／相关性选择。模拟分析展示关联，允许纠正；“交换机”等缺少事实的记录只询问相关补充。
- **娱乐券**：每张券显示序号，剩余时长独立保存；新券使用完整时长、旧券只续用余额，本次已用从零开始。上一段尚未确认结束时会明确提醒，避免以为已经开始新券。
- **奖励偏好**：问卷第 5 组末题填写长期购买力偏好；普通设置只显示摘要和返回问卷更新入口，不需要每天重设。
- **添加想要的奖励**：奖励商店右上“＋ 添加想要的奖励”，填写奖励内容、物品／体验或计时娱乐、时长、可选现实价格与说明，不填写金币价。点击“AI 建议价格（模拟）”后查看建议金额及依据；可以返回补充信息重新建议，接受后才加入商店。关闭建议不创建商品，草稿可恢复。Demo 用脚本模拟，正式版本必须真实模型分析。

可以这样复验两张券：兑换第一张 30 分钟券 → 计时中“说明情况”填写实际 5 分钟并保存 → 结束并确认 → 再兑换第二张 → 确认开始时应显示“第 2 张券 · 30 分钟”。回到奖励区，第一张仍剩 25 分钟。当前本机虚构状态会保留，刷新新版 HTML 即可，不必重置。
