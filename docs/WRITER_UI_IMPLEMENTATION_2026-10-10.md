## 4. 两项具体实现决定

### 4.1 设置定位与组件身份

App 当前 RouterView key 包含 route.fullPath；本轮不改全局 key。我的分组入口指向 `/settings`，设置顶部提供三个或必要数量的区块目录按钮。按钮执行顺序为：显式展开目标 details（若有）→nextTick→滚动目标→焦点移到目标标题。可使用 `scroll-margin` 预留空间；减少动画偏好下不平滑滚动。

目录按钮必须 `type="button"`，不触发提交、不调用 API、不更改 hash/query。模型/Key 输入只在组件内保留，不为防重挂载把 Key 写入 localStorage。折叠用保留实例的方式；不在宽度变化时渲染另一套模型表单。

### 4.2 图表生命周期与可用宽度

能力数值列表承担完整信息，雷达辅助表达。单列时雷达默认收起，足够宽的桌面默认展开；随后记录用户的手动选择，resize 不自动反复开合。趋势的手机 select 和桌面按钮绑定同一 growthDim，切布局不重置选择，不复制两个独立状态源。

仅当图容器实际宽高非零时 init；展开后 nextTick，再 render/resize。用实际容器变化与明确的展开事件处理尺寸，不只监听窗口 resize。卸载清理 observer、事件与实例。等待中的读取返回不得在已卸载页面创建图实例。

热力图可保持近四个月及局部横向滚动，页面自身不能横向溢出。滚动区提供可访问名称、可见焦点和键盘使用方式；同卡的日期/数量文本提供替代。不得全站 overflow-x:hidden 掩盖溢出，不改变真实日期、分段、轴范围和历史口径。
